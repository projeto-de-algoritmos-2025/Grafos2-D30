## Instalação e Uso

1. Clone o repositório na pasta de sua preferência:

```bash
git clone https://github.com/projeto-de-algoritmos-2025/Grafos2-D30
```

2. Navegue até a pasta :

```bash
cd Grafos2-D30
```

3. Execute o arquivo *main.py*:

```bash
python main.py
```
